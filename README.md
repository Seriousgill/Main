# New Delhi Palace Website
Node.js + Express + EJS + MySQL full-stack site with public pages and secure admin dashboard.

## Pages
- Home, Menu, Catering, Gallery, Contact
- Admin: login, dashboard, categories, menu, gallery, settings, inquiries

## Run
1. Copy `.env.example` to `.env` and update DB credentials.
2. Import `database.sql` into MySQL.
3. `npm install`
4. `npm start`

Default admin: `admin` / `admin123`
